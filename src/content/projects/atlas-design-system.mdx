Atlas began as a rescue mission. Three product teams, three button components,
zero shared language. We replaced the sprawl with a single source of truth:
a layered token system (primitive → semantic → component) that compiles to CSS
custom properties, native platform values, and documentation in one pass.

## What I did

- Designed the **three-tier token architecture** and the build pipeline that
  emits it to web, iOS and Figma simultaneously.
- Built 38 components as framework-agnostic web components with scoped styles.
- Wrote the contribution model and the automated accessibility test suite
  (axe + manual audits) that gates every release.

## Outcome

Adoption hit 40+ product surfaces in two quarters. Time-to-ship for a new
screen dropped by roughly a third, and the design–engineering handoff became
a non-event: the tokens *are* the spec.

> The system should be invisible. You only notice it when it's missing.
